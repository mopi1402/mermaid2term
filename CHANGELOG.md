# Changelog

## 1.0.0

- First release: eighteen mermaid diagram kinds drawn as Unicode art in the terminal, read from mermaid's own syntax and configuration keys.
- mermaid 12's eleven themes, each replaying its own `updateColors`, plus a light-terminal mirror of every palette.
- Three border modes (`default`, `padless`, `borderless`), a `compat` character set for fonts missing a glyph, and a width and height budget the drawing is refitted to.
- Where a drawing departs from mermaid on purpose, the reason is recorded in `docs/divergences.md`.
